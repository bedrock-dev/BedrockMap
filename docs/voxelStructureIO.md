# 体素结构导入、导出与复制

本文说明 3D 体素预览/区块编辑器中结构操作的参数和当前行为。

## 适用范围

- 世界区块和 3D 视图中的结构编辑。
- 独立打开的 `mcstructure` 只读预览。
- 应用内部的结构复制与粘贴。

导入、粘贴和删除只在允许方块编辑的世界会话中显示。独立 `mcstructure` 预览只能导出或复制。

## 参数含义

| 参数 | 适用操作 | 含义 |
|---|---|---|
| 包含实体 | 导出、复制、导入、粘贴、删除 | 控制普通生物实体。方块实体属于方块数据，不受此参数控制。 |
| 导出时包含空气 | 导出、复制 | 控制结构中的空气方块是否写入输出结构，默认开启。 |
| 导出时包含结构空位 | 导出、复制 | 控制 `minecraft:structure_void` 是否写入输出结构，默认关闭。 |
| 使用新版格式导出 | 导出、复制 | 使用 mcstructure format version 2；关闭时使用 version 1。 |
| 替换非空气方块 | 导入、粘贴 | 用当前结构中的方块覆盖存档方块。勾选时允许覆盖目标已有非空气方块；未勾选时跳过这些目标坐标。 |
| 压缩网格 | GLB 导出 | 独立于结构导入/导出，仅影响 GLB 网格压缩。 |

导入会自动识别 mcstructure 格式；粘贴沿用复制时写入内部剪贴板的格式。

## 当前导出和复制行为

导出到文件和复制到内部剪贴板共用底层 `BlockVolumeSource::exportStructure()`：

- 导出额外负责将原始字节写入文件。
- 复制额外负责将原始字节写入 `BinaryClipboard::PayloadKind::Mcstructure`。
- 两者使用同一个 `StructureExportOptions`。

### 世界结构

当前世界结构导出：

- `包含实体` 关闭时，不导出普通生物实体。
- 方块实体始终跟随方块导出。
- `导出时包含空气` 开启时，先使用空气填充整个选区，再覆盖非空气方块。
- `导出时包含空气` 关闭时，跳过 `minecraft:air` 和 `minecraft:unknown`。
- `导出时包含结构空位` 关闭时，跳过名称严格等于 `minecraft:structure_void` 的方块。
- `minecraft:unknown` 始终不视为有效方块。
- 选区位置决定结构的 `structure_world_origin`。

### 独立 mcstructure

当前独立结构导出：

- `包含实体` 关闭时，不导出普通生物实体。
- 方块实体始终跟随方块导出。
- `导出时包含空气` 开启时，保留结构中的空气方块。
- `导出时包含空气` 关闭时，跳过空气方块。
- `导出时包含结构空位` 关闭时，跳过名称严格等于 `minecraft:structure_void` 的方块。
- `minecraft:unknown` 始终跳过。
- 未定义或缺失的方块条目保持缺失，不主动补空气。

### 导出格式

| 选项 | mcstructure format version |
|---|---:|
| 关闭 | 1 |
| 开启 | 2 |

## 当前导入和粘贴行为

### 导入

1. 点击 `导入` 打开 mcstructure 文件选择器。
2. 文件以异步任务解析。
3. 成功后显示导入预览，并将选区调整为结构尺寸。
4. 用户移动选区位置。
5. 点击 `Confirm import` 后写入世界。

### 粘贴

1. 从应用内部剪贴板读取 `Mcstructure` 原始字节。
2. 剪贴板为空时直接报错。
3. 后续解析、预览和确认流程与导入完全一致。

### 导入覆盖规则

导入和粘贴的本质是：用当前结构里所有已定义的方块，覆盖存档中对应坐标的方块。

这里的“结构方块”可以是空气，也可以是普通方块或结构空位，不区分它们的类型。选项只决定遇到目标已有非空气方块时是否跳过：

| 目标存档坐标 | 勾选“替换非空气方块” | 未勾选 |
|---|---|---|
| 空气 | 写入结构中的方块；如果也是空气则保持空气 | 写入结构中的方块；如果也是空气则保持空气 |
| 非空气方块 | 用结构中的方块覆盖；结构方块是空气时清除目标 | 跳过该坐标，保留目标原方块 |

补充规则：

- 只有结构中已定义的坐标参与导入；结构没有定义的坐标始终不修改。
- 勾选后，导入范围为结构中所有已定义坐标；是否跳过非空气方块只取决于目标存档，不取决于结构中的方块类型。
- 目标方块列的任意层存在非空气方块，就视为目标非空气坐标。
- 单个坐标的所有层整体替换；结构中缺少的层写为空气，不保留目标旧层。
- 方块实体只随成功写入的方块列处理。
- 同坐标方块实体由 `compact()` 保留最后写入的新实体。
- 替换方块列但结构没有新方块实体时，删除该位置旧方块实体。
- `包含实体` 只新增普通实体，不删除目标区域已有普通实体。

### 当前范围和区块行为

- 选区的 X/Z 必须位于当前 3D 模型范围内。
- 选区尺寸必须与导入结构尺寸一致。
- 目标 X/Z 覆盖的全部 chunk 使用 `AsyncLevelLoader::isChunkAbsent()` 和 `getRawChunk()` 预检。
- 任意目标 chunk 不存在、无法读取或无法解析时，整个导入/粘贴失败。
- 导入不会创建缺失 chunk。
- Y 方向不按当前 3D 预览范围或固定世界高度裁剪；这是为了支持没有可靠高度信息的自定义维度，以及仅导入结构上半部分的情况。

### 当前提交方式

1. 预检并读取全部目标 chunk。
2. 在临时 `bl::chunk` 对象中完成所有方块、方块实体和普通实体修改。
3. 全部修改成功后，调用 `AsyncLevelLoader::putRawChunks()` 一次性写入 `RawChunkCache`。
4. 任意预检或修改失败时，不写入 raw cache。
5. 写入 raw cache 后刷新区域缓存，并只触发一次 dirty 通知。
6. 不直接写 LevelDB；世界保存时由 `RawChunkCache::commit()` 使用单个 LevelDB `WriteBatch` 统一持久化。
7. 在保存前退出应用会丢失这些未保存修改。

### Y 方向越界

允许导入结构在 Y 方向超过当前 3D 预览范围：

- X/Z 仍执行当前范围和目标 chunk 存在性检查。
- Y 方向不执行固定世界高度裁剪，也不限制在当前 3D 模型高度内。
- 自定义维度可能无法可靠读取高度范围，因此不引入盲目的维度高度判断。
- 选区在 Y 方向超出当前预览时，结构仍然整体进入导入暂存和原子提交流程。
- 当用户只需要结构的一部分时，可通过选区位置让部分内容落在当前预览之外，不应因此拒绝整个导入。
